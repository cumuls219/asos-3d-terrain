3D 기상 분석지도 · 사용 설명서

1. 빠른 사용 순서

특정 시각 날짜·시각 선택 → 관측자료 조회 → 기온/습도/강수 또는 바람 분석장을 선택합니다.
일극값 날짜와 요소(일강수량·일최고기온·일최저기온·일최대풍속) 선택 → 조회 → 일극값장을 켭니다.

2. 지도 · 관측망

  • 위성: 기본 ON. 배경 위성영상을 켜거나 끕니다.
  • 3D 건물: V-World 건물 레이어를 켜거나 끕니다.
  • 시군구 경계: V-World WMS LT_C_ADSIGG 행정구역 경계를 표출합니다. 분석장과 독립적으로 ON/OFF 됩니다.
  • 주요 산: 기상청 산악예보 지점정보의 정상 좌표·고도를 기준으로 산명(고도m)를 표출합니다. 고도가 높은 산은 넓은 시야에서, 낮은 산은 확대 시 나타나도록 자동으로 과밀을 줄입니다. 산 표시를 클릭하면 좌표·고도·자료 기준을 확인할 수 있습니다.
  • ASOS / AWS / 항만: 관측망별 마커·라벨을 독립적으로 제어합니다.

3. 스칼라 분석장

  • 기온, 상대습도, 강수, 일극값을 관측지점 값으로부터 IDW(p=2) 보간합니다.
  • 임의 외삽을 줄이기 위해 유효 관측지점의 볼록껍질 내부만 분석장으로 표출합니다.
  • 강수는 15분·60분·12시간·일누적 중 선택할 수 있습니다.
  • 분석장 투명도를 조절하여 지형·위성영상과 함께 볼 수 있습니다.

4. 바람 분석장

  • 1분 또는 10분 풍향·풍속을 선택합니다. 둘 다 있으면 10분 평균을 우선 사용합니다.
  • 풍향을 직접 보간하지 않고 관측 풍향·풍속을 U/V 성분으로 변환한 뒤 각각 IDW 보간합니다.
  • 밀도·길이·벡터 두께를 조절할 수 있습니다.

5. 색상과 해석

  • 기온: 청색 → 황색 → 적색 계열
  • 습도: 갈색/황색 → 청록/청색 계열
  • 강수: 노랑 → 연두/초록 → 주황 → 적색 → 자주 계열
  • 일최대풍속: 연황 → 주황 → 적색 계열

6. 자료와 주의사항

관측값과 분석장은 구분해야 합니다. 지점 팝업·라벨 값은 관측자료이고, 배경에 연속적으로 보이는 색상장은 IDW 보간 결과입니다. 분석장은 관측되지 않은 위치의 실제값을 의미하지 않습니다.
경계 레이어가 나타나지 않을 경우 V-World WMS 인증 범위 또는 네트워크 상태를 확인하세요. 경계 실패가 기상자료 조회·분석 계산을 중단시키지는 않습니다.
